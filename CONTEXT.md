# CONTEXT.md — ai-scout

> Shared language for ai-scout project
> Based on: https://github.com/mattpocock/skills

## Domain Terms

**ContentCombine**:
Мультинишевый агрегатор контента с мультиагентной архитектурой.
_Избегай_: агрегатор, система контента

**Collector**:
Агент сбора данных (Habr, Medium, Twitter, Telegram).
_Избегай_: сборщик, парсер

**Analyst**:
Агент анализа (скоринг, кластеризация, тренды).
_Избегай_: анализатор, оценщик

**Curator**:
Агент экспорта (Telegram дайджесты, алерты).
_Избегай_: экспортер, форматировщик

**Workflow**:
Детерминированный пайплайн (70% системы).
_Избегай_: пайплайн, конвейер

**Autonomous**:
LLM-компонент для кластеризации и генерации (30% системы).
_Избегай_: автономный агент, LLM

**Score**:
Оценка контента по триггерам, сущностям, комбинациям, свежести.
_Избегай_: оценка, рейтинг

**Cluster**:
Группировка контента по темам/тегам.
_Избегай_: группировка, категоризация

**Digest**:
Подборка топ-10 материалов для Telegram.
_Избегай_: дайджест, подборка

**Pexels**:
API для поиска фото к статьям.
_Избегай_: фото, изображения

## Relationships

- **ContentCombine** использует 3 **агента** (Collector → Analyst → Curator)
- **Collector** собирает контент, **Analyst** скорит, **Curator** экспортирует
- **Workflow** определяет порядок **агентов**
- **Autonomous** компоненты работают внутри **Workflow**
- **Score** используется для фильтрации контента
- **Cluster** группирует отскоренный контент
- **Digest** формируется из **кластеров**
- **Pexels** добавляет фото к **Digest**

## Flagged Ambiguities

- "агрегатор" vs "ContentCombine" — resolved: используем "ContentCombine"
- "агент" vs "компонент" — resolved: "агент" для Router/KB/Generator, "компонент" для Collector/Analyst/Curator
- "скоринг" vs "оценка" — resolved: "скоринг" для процесса, "оценка" для результата
- "дайджест" vs "подборка" — resolved: "дайджест" для Telegram формата
